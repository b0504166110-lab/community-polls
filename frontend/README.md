# סקרים בקהילה - צד לקוח

אתר שבו חברי קהילה יוצרים סקרים, מצביעים ורואים תוצאות בדיאגרמות. מנהל מאשר כל סקר לפני פרסום.
הפרונט מתקשר עם השרת שבתיקיית `backend-project` (ראו שם את `README.md` ואת `docs/SPEC.md`).

## טכנולוגיות
React · TypeScript · Vite · React Router · Redux Toolkit (מצב התחברות) · TanStack Query (נתוני שרת) · Axios · ECharts (דיאגרמות) · Vitest + Testing Library (בדיקות)

## הרצה
```bash
npm install
npm run dev      # שרת פיתוח בכתובת http://localhost:5173
npm test         # הרצת הבדיקות
npm run build    # בדיקת טיפוסים ובניית גרסת ייצור
```
השרת (`backend-project`) צריך לרוץ במקביל, בפורט 3000.

## מסכים והרשאות

| נתיב | מסך | מי רשאי |
|---|---|---|
| `/` | דף נחיתה | כולם |
| `/polls` | רשימת סקרים (חיפוש, סינון, מיון, עמודים) | כולם |
| `/login`, `/register` | התחברות והרשמה | אורחים (מחוברים מועברים ל-`/polls`) |
| `/polls/:id` | פרטי סקר, הצבעה ותוצאות | מחוברים בלבד |
| `/polls/new` | יצירת סקר | מחוברים בלבד |
| `/polls/:id/edit` | עריכת סקר | מחוברים בלבד |
| `/my-polls` | הסקרים שלי | מחוברים בלבד |
| `/admin` | ניהול סקרים (אישור, דחייה, הסתרה) | מנהל בלבד |

אורח שמנסה להיכנס למסך שמיועד למחוברים מועבר להתחברות. ההגנה קיימת גם בצד השרת, שמחזיר 401.

## מבנה התיקיות (`src`)
- `api/` - פונקציות הקריאה לשרת, וקליינט Axios משותף
- `components/` - רכיבים לשימוש חוזר (כרטיסי סקר, טפסים, דיאגרמות, סינון ועמודים)
- `pages/` - מסך לכל נתיב
- `routes/` - הגדרת הנתיבים ו-`ProtectedRoute`
- `store/` - מצב ההתחברות (Redux)
- `utils/` - ולידציה והמרות של טפסי סקר
- `test/` - כלי עזר לבדיקות
